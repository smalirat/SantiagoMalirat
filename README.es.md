## Proyectos Académicos

Proyectos desarrollados como esfuerzos colaborativos para materias universitarias.

- [TP DSI – Diseño de Sistemas de Información](https://github.com/smalirat/tp-dsi-1)
  Trabajo práctico de la materia *Diseño de Sistemas de Información*. Desarrollo de una plataforma web (MetaMapa) aplicando arquitectura MVC y diseño de API REST. Construido con Java y Javalin, implementa persistencia relacional mediante JPA/Hibernate, usando PostgreSQL como motor de base de datos. Aplicación de patrones de diseño para la integración con APIs de fuentes externas (Adapter), y renderizado *server-side* utilizando Handlebars.

- [SSL – Laboratorio de Sintaxis y Lenguaje](https://github.com/smalirat/SSL-Grupo-7)
  Ejercicios relacionados con el desarrollo de un compilador escrito en C, Flex y Bison, abarcando análisis léxico y sintáctico de la materia *Sintaxis y Semántica de los Lenguajes*.

- [TP TGC – Técnicas de Gráficos por Computadora](https://github.com/smalirat/TP-TGC-2025-1C-FIFO)
  Trabajo práctico de la materia *Técnicas de Gráficos por Computadora*, con el objetivo de crear un entorno interactivo y de simulación gráfica 3D. Programado en C# utilizando el framework MonoGame sobre la plataforma .NET. Implementación práctica del pipeline gráfico de bajo nivel (DirectX/OpenGL), aplicando transformaciones matriciales y proyecciones espaciales. Incluye la programación de Shaders personalizados (en HLSL/GLSL) para el cálculo de iluminación en tiempo real y efectos visuales, mapeo de texturas, rasterización y manejo de cámaras aplicados al diseño de videojuegos.

- [TP SO – Sistemas Operativos](https://github.com/smalirat/Tp-so)
  Desarrollo en C de un sistema distribuido que simula los componentes de un Sistema Operativo sobre Linux. Implementación modular (Kernel, CPU, Memoria y E/S) comunicada mediante Sockets TCP. Aplicacion de concurrencia y multithreading (pthreads), sincronización, algoritmos de planificación de procesos, y administración de memoria virtual (Paginación, MMU y TLB). Compilación y orquestación manejada con Makefiles.

- [TP GDD – Gestión de Datos](https://github.com/smalirat/GDD-TP-2C-2025)
  Proyecto centrado en el diseño y modelado de una base de datos relacional, así como en la elaboración de consultas SQL y T-SQL para la migración de datos desnormalizados y la visualización orientada a Business Intelligence, correspondiente a la materia *Gestión de Datos*.

- [TP DDS – Desarrollo de Software](https://github.com/smalirat/TP-DDS)
  Trabajo práctico de la materia *Desarrollo de Software*, consistente en la simulación de una aplicación web tipo Airbnb. Con backend construido sobre Node.js, exponiendo una API REST estructurada bajo una arquitectura MVC multicapa rigurosa (Rutas, Controladores, Servicios y Repositorios) orientada a objetos. Y el frontend es una SPA desarrollada con React y Vite. Incluye modelado de datos NoSQL (Schemas) para el uso de Mongo DB, pruebas automatizadas (unitarias y de integración) con Jest y Supertest, y orquestación del entorno de desarrollo utilizando Docker.
